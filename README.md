## Chỉnh sửa code

### Frontend (index.html)
1. Sửa file `index.html` — tất cả CSS + JS nằm trong 1 file
2. Push lên GitHub → tự động deploy qua GitHub Pages (1-2 phút)

### Backend (Code.gs)
1. Sửa file `apps-script/Code.gs` (local reference)
2. Vào Google Sheet → Extensions → Apps Script → paste code mới
3. Deploy → Manage deployments → chọn deployment hiện tại → Edit (icon bút chì) → Version: New version → Deploy
